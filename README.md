# ป่าข้อเฟรม — วันนี้ในอดีต : 18 ตุลาคม 1867 "วันที่อเมริกาได้อลาสกา"

คลิปโมชั่นการ์ตูนแนวตั้ง (1080×1920, 60fps) พื้นขาว ตัวหนังสือดำ ซับไทย เสียงพากย์อย่างเดียว
เว้นพื้นที่ด้านล่างไว้ให้ชื่อ/คำอธิบายของแพลตฟอร์ม

**ไฟล์ผลลัพธ์:** `output/alaska_18oct_1080p60.mp4`

## ใช้เสียงของคุณเอง

1. อัดเสียงอ่านบทข้างล่าง **ตามลำดับ** ในไฟล์เดียว (มือถือก็ได้ m4a/mp3/wav)
2. **เว้นจังหวะ ~1 วินาทีระหว่างบรรทัด** (ระบบใช้ช่วงหยุดนี้แบ่งซับ) ไม่ต้องห่วงช่วงเงียบ ระบบตัดให้กระชับเอง
3. อ่านด้วยพลังงานสูง ยิ้มตอนพูด เน้นคำที่มี "!" — ถ้าอยากเร็วขึ้นอีกใช้ tempo 1.1–1.2
4. รัน `./make.sh my_voice.m4a 1.1`

### บทอ่าน
1. ลองนึกภาพตามนะ...
2. เข้านอนคืนวันศุกร์ที่ 6 ตุลาคม
3. ตื่นมา... เป็นวันศุกร์ที่ 18 ซะงั้น!
4. 12 วันหายไปไหน? เรื่องจริงนะ!
5. วันนี้ในอดีต 18 ตุลาคม 1867
6. ที่ดินแดนน้ำแข็งชื่อ "อลาสกา"
7. ตอนนั้นอลาสกา ยังเป็นของรัสเซีย
8. แต่รัสเซียเพิ่งแพ้สงคราม เงินหมดกระเป๋า
9. แถมกลัวอังกฤษ จะมาฮุบไปฟรี ๆ
10. งั้นขายให้อเมริกาเลยดีกว่า!
11. ปิดดีลที่ 7.2 ล้านดอลลาร์
12. ตกเอเคอร์ละ 2 เซนต์ ถูกยังกับลดล้างสต็อก!
13. ทั้งที่ใหญ่เกือบ 3 เท่าของไทย
14. แต่คนอเมริกัน กลับขำกันทั้งประเทศ
15. ล้อว่าเป็น "ตู้เย็นของซิวเวิร์ด"
16. แซวรัฐมนตรีซิวเวิร์ด ซื้อน้ำแข็งมาทำไม!
17. แล้ววันที่ 18 ตุลาคมก็มาถึง
18. ที่เมืองซิตกา ทหารสองชาติ ยืนตรง
19. ธงรัสเซียค่อย ๆ ลดลง...
20. แต่ธงดันพันเสา ไม่ยอมลง!
21. ทหารต้องปีนขึ้นไปแกะ
22. ธงร่วงลงบนดาบปลายปืนพอดี
23. ภรรยาผู้ว่าการ ถึงกับเป็นลม!
24. ธงอเมริกาขึ้นแทนที่
25. อลาสกาเปลี่ยนมาใช้ ปฏิทินแบบอเมริกา
26. ศุกร์ที่ 6 เลยกระโดดไปศุกร์ที่ 18
27. ได้ศุกร์สองวันติด! นี่แหละคำตอบ
28. แล้วคนที่เคยขำ... ก็เงียบกริบ
29. เพราะไม่กี่สิบปีต่อมา เจอทอง!
30. ร้อยปีต่อมา เจอน้ำมันมหาศาล!
31. ตู้เย็นที่โดนล้อ กลายเป็นขุมทรัพย์
32. วันนี้อลาสกา คือรัฐที่ 49 ของอเมริกา
33. และ 18 ตุลาคม คือ "วันอลาสกา"
34. บทเรียนจากอดีตคือ...
35. สิ่งที่คนหัวเราะเยาะวันนี้ อาจเป็นขุมทองในวันหน้า
36. ถ้าเป็นคุณ... จะกล้าซื้อไหม?
37. เมนต์บอกกัน แล้วพรุ่งนี้มาย้อนอดีตกันใหม่!

## สร้างใหม่

```bash
./make.sh                         # เสียง AI ชั่วคราว
./make.sh my_voice.m4a 1.1        # เสียงตัวเอง เร่ง 1.1 เท่า
python3 src/render.py --still 45  # ดูภาพนิ่งวินาทีที่ 45
```

ต้องมี `ffmpeg` และ Python 3 (`pip install -r requirements.txt`)
ฟอนต์ Mali / Kanit (SIL OFL) อยู่ใน `assets/fonts`

## โครงสร้าง

```
src/script_data.py   บท + ซับ
src/tts.py           เสียง AI ออฟไลน์ (ชั่วคราว)
src/voice.py         เสียงอัดเอง: ตัดเงียบ เร่งความเร็ว แบ่งบรรทัด ซิงก์ซับ
src/timeline.py      จัดจังหวะเสียงต่อกันแบบกระชับ -> timeline.json
src/gfx.py           ไลบรารีวาดการ์ตูน
src/scenes.py        แอนิเมชันแต่ละฉาก
src/render.py        คอมโพส ซับ safe area -> mp4 พร้อมเสียง
```

แนวทางสไตล์ของช่องอยู่ใน `CLAUDE.md`
