## โครงสร้างโปรเจกต์

```
src/script_data.py   บทพากย์ + ซับ (แก้บทที่นี่)
src/tts.py           เสียงพากย์ไทยออฟไลน์ (sherpa-onnx + Meta MMS Thai) -> timeline ซิงก์ซับอัตโนมัติ
src/gfx.py           ไลบรารีวาดการ์ตูนลายเส้น (ตัวละคร หมี/ลุงแซม/ซิวเวิร์ด/สิงโต ฯลฯ)
src/scenes.py        แอนิเมชันแต่ละฉาก + จุดลงเสียงเอฟเฟกต์ (CUES)
src/render.py        คอมโพส ซับ เอฟเฟกต์ฟิล์มเก่า (grain, flicker, รอยขีด, ฝุ่น, vignette) -> mp4
src/audio.py         ดนตรีและ SFX สังเคราะห์ด้วยโค้ด (ไม่มีลิขสิทธิ์) + ducking ใต้เสียงพูด
make.sh              สร้างทั้งหมดในคำสั่งเดียว
```

## สร้างใหม่ / แก้ไข

```bash
./make.sh                               # ทำทุกขั้นตอน
python3 src/render.py --still 45.0      # ดูภาพนิ่งที่วินาทีที่ 45 -> build/still_45.00.png
```

ต้องมี `ffmpeg` และ Python 3 (numpy, pillow, pycairo, sherpa-onnx)
ฟอนต์: Mali / Kanit (SIL Open Font License) อยู่ใน `assets/fonts`

## คำแนะนำเพิ่มเติม

- **เสียงพากย์**: ตอนนี้ใช้เสียง AI แบบออฟไลน์ (MMS) ซึ่งยังฟังเป็นหุ่นยนต์อยู่บ้าง ถ้าอยากให้เป็นธรรมชาติขึ้น
  ให้อัดเสียงตัวเองตามบทด้านบน หรือใช้ TTS คุณภาพสูง (เช่น Azure `th-TH-PremwadeeNeural`, ElevenLabs)
  แล้ววางไฟล์เป็น `build/narration.wav` — โค้ดจะซิงก์ซับใหม่ได้ถ้าปรับ `tts.py` ให้ใช้เวลาจากไฟล์นั้น
- **ปกคลิป (thumbnail)**: แนะนำใช้เฟรมวินาทีที่ ~47 (ธงพันเสา) หรือ ~69 (ตู้เย็นเปิดเป็นทอง) + ข้อความ "ซื้อแผ่นดินแค่ 2 เซนต์?!"
- **แคปชั่น/แฮชแท็ก**: `อเมริกาซื้ออลาสกาแค่เอเคอร์ละ 2 เซนต์ แต่โดนล้อทั้งประเทศ... #วันนี้ในอดีต #ประวัติศาสตร์ #อลาสกา #เรื่องเล่า #ความรู้รอบตัว`
- **ซีรีส์ต่อ**: ใช้โค้ดเดิมได้เลย — แก้บทใน `script_data.py` แล้ววาดฉากใหม่ใน `scenes.py`
