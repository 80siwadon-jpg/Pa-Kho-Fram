# ป่าข้อเฟรม — วันนี้ในอดีต : 18 ตุลาคม 1867 "วันที่อเมริกาได้อลาสกา"

คลิปโมชั่นการ์ตูนแนวตั้ง (1080×1920, 60fps) พื้นขาว ตัวหนังสือดำ ซับไทย เสียงพากย์อย่างเดียว
เว้นพื้นที่ด้านล่างไว้ให้ชื่อ/คำอธิบายของแพลตฟอร์ม

**ไฟล์ผลลัพธ์:** `output/alaska_18oct_1080p60.mp4`

## เสียงพากย์

ทุกคลิปใช้โทนเสียงเดียวกับ `assets/voice/reference_tesla.wav` และเล่าแบบสารคดี (รายละเอียดใน `CLAUDE.md`)

1. นำบท `output/script_alaska.txt` ไปสร้างเสียงด้วยเครื่องมือเดิม (บรรทัดละประโยค ให้มีช่วงหยุดระหว่างบรรทัด)
2. ส่งไฟล์เสียงมา หรือรันเอง `./make.sh voice.wav 1.1` (1.1 = เร่งความเร็ว 10%)

## สร้างใหม่

```bash
./make.sh                         # เสียง AI ชั่วคราว
./make.sh my_voice.m4a 1.1        # เสียงตัวเอง เร่ง 1.1 เท่า
python3 src/render.py --still 45  # ดูภาพนิ่งวินาทีที่ 45
```

ต้องมี `ffmpeg` และ Python 3 (`pip install -r requirements.txt`)
ฟอนต์ Mali / Kanit (SIL OFL) อยู่ใน `assets/fonts`

## โครงสร้าง

```
src/script_data.py   บท + ซับ
src/tts.py           เสียง AI ออฟไลน์ (ชั่วคราว)
src/voice.py         เสียงอัดเอง: ตัดเงียบ เร่งความเร็ว แบ่งบรรทัด ซิงก์ซับ
src/timeline.py      จัดจังหวะเสียงต่อกันแบบกระชับ -> timeline.json
src/gfx.py           ไลบรารีวาดการ์ตูน
src/scenes.py        แอนิเมชันแต่ละฉาก
src/render.py        คอมโพส ซับ safe area -> mp4 พร้อมเสียง
```

แนวทางสไตล์ของช่องอยู่ใน `CLAUDE.md`
